# Blog CRUD Laravel

Aplikasi Blog CRUD sederhana yang dibuat menggunakan Laravel sebagai tugas Pemrograman Web.

## Fitur

- Menampilkan daftar post
- Menambahkan post
- Melihat detail post
- Mengedit post
- Menghapus post
- Validasi form
- Menampilkan pesan sukses/gagal
- Pagination
- Konfirmasi sebelum menghapus post
- Responsive UI

## CRUD

| Fitur | Keterangan |
|---|---|
| Create | Menambahkan post baru |
| Read | Menampilkan daftar dan detail post |
| Update | Mengubah data post |
| Delete | Menghapus post |
